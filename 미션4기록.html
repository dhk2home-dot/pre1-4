미션 4 기록

사용한 AI 이름: VS Code의 Copilot SDK를 사용하는 AI assistant

주요 대화 캡처 파일명: 별도 대화 캡처 파일은 없음. 대화와 산출물 요약은 산출물_제작_대화요약.md에 기록

더한 기능과 고른 이유

  • 영화별 기본 포스터 그래픽 표시 — 카드에서 영화를 쉽게 구분할 수 있도록 추가
  • 영화 제목·포스터 주소·티어 입력 폼 — 새 영화를 원하는 등급에 포스터와 함께 추가할 수 있도록 추가
  • 넓은 화면에서 한 줄로 보이는 반응형 입력 폼 — 입력 항목을 한눈에 보고 좁은 화면에서는 잘림을 방지하도록 수정
  • 카드별 삭제와 확인창 — 잘못된 삭제를 방지하고 원치 않는 영화를 목록에서 제거할 수 있도록 추가
  • 카드 오른쪽 위 원형 × 삭제 버튼 — 삭제 기능을 카드 안에서 알아보기 쉽게 배치
  • 기능 변경에 맞춘 기획 문서와 HTML 문서 — 완성된 동작과 기준을 확인하고 공유할 수 있도록 정리

받은 파일별 조치

받은 파일 맞지 않은 완성 기준 한 일 (고치기 / 원래 파일로 돌아가기 / 완성)
영화_원본.html 원래 기획서.md의 완성 기준은 확인 당시 모두 충족. 추가 요청으로 포스터 표시가 필요했음 원본은 보존하고 기본 그래픽 포스터를 넣은 영화_수정본.html을 별도로 완성
영화_수정본.html 기본 포스터는 있었으나 포스터 주소와 티어를 입력하는 기능이 필요했음 제목·포스터 주소·티어를 입력할 수 있는 영화_수정본1.html을 별도로 완성
영화_수정본1.html 영화 카드별 삭제 기능이 필요했음 확인창이 있는 삭제 기능을 영화_수정본2.html에 추가하고, 삭제 버튼을 카드 오른쪽 위 ×로 수정
영화_수정본2.html 기능 확인 후 추가 수정 요청 없음 삭제 확인·취소, 저장, 초기화 및 × 버튼 위치를 확인해 완성
기회서.md 작업 폴더에서 해당 이름의 파일을 찾지 못함 사용자 확인을 거쳐 기획서.md를 기준으로 기회서_수정본.md 작성
기회서_수정본.md Markdown 문서의 HTML 버전이 필요했음 내용을 기획서_수정본.html로 변환해 별도 저장
영화_완성본.html 사용자가 최종 산출물 파일로 제시했으며, 이 기록 작성 시 별도 검증 내역은 없음 최종 산출물로 기록
