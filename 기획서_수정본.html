내 영화 티어리스트

누가 쓰나

  • 나와 영화를 좋아하는 친구들

무엇을 하려고

  • 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

화면과 동작

  • 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
  • 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
  • 영화 추가 폼에서 제목, 포스터 이미지 주소, 티어리스트를 입력하거나 선택하고 ‘추가’를 누르면 선택한 칸에 카드가 생깁니다. ‘미분류’를 선택하면 아직 안 정한 영화에 추가됩니다.
  • 제목은 필수이며, 이미 등록된 제목과 빈 제목은 추가하지 않습니다.
  • 포스터 이미지 주소는 선택 항목입니다. http:// 또는 https:// 주소를 사용할 수 있습니다. 주소를 입력하지 않으면 파일에 포함된 기본 그래픽 포스터를 표시하고, 입력한 이미지 주소를 불러오지 못한 경우에도 기본 그래픽으로 대체합니다.
  • 포스터가 표시된 카드에는 영화 제목과 함께 오른쪽 위에 원형 × 삭제 버튼이 있습니다. 삭제 버튼을 누르면 확인 메시지가 나오며, 확인한 경우에만 영화가 목록에서 삭제됩니다. 취소하면 카드가 유지됩니다.
  • 영화 목록과 티어 배치는 같은 브라우저에 자동 저장되며, 삭제한 결과도 저장됩니다.
  • ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아가고 추가한 영화는 삭제됩니다.
  • 넓은 화면에서는 제목·포스터 주소·티어 선택·버튼을 한 줄로 표시합니다. 화면 폭이 좁으면 입력 폼이 줄을 바꾸며, 오른쪽으로 잘리지 않도록 합니다.
  • 기본 그래픽 포스터는 HTML 안에 포함되어 별도 파일 없이 표시됩니다. 직접 입력한 이미지 주소의 포스터를 표시하려면 해당 이미지 주소에 인터넷으로 접속할 수 있어야 합니다.

필요한 자료

  • 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

완성 기준

  • 영화가 한 티어에만 있고, 옮긴 티어에 남습니다.
  • 제목과 선택한 티어를 입력하면 카드가 해당 칸에 추가됩니다.
  • 포스터 주소를 입력하면 해당 이미지가 표시되고, 주소가 없거나 이미지 표시가 실패하면 기본 그래픽 포스터가 표시됩니다.
  • 같은 브라우저에서 같은 파일을 다시 열어도 영화와 티어가 남습니다.
  • 카드의 × 버튼은 오른쪽 위에 보이고, 확인했을 때만 해당 영화가 삭제됩니다.
  • 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
  • ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
  • 기본 포스터는 외부 파일 없이 표시되며, 로그인·서버 실행 없이 HTML 한 장으로 열립니다.
  • 빈 제목과 중복 제목은 추가하지 않습니다.
